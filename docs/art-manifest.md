# Art manifest

Generated by `node scripts/art-manifest.mjs`. Do not edit by hand.

## Why every game feels the same

23 games share 8 symbol sets:

| Symbol set | Games dealing identical symbols |
| --- | --- |
| `orb` | 6 — Neon Alley, Frost Peak, Carnival Row, City Lights, Aurora, Supernova |
| `fruit` | 4 — Juwa Classic, Lucky Sevens, Triple Bar, Fruit Stand |
| `asian` | 3 — Jade Temple, Spice Market, Dragon's Hoard |
| `jungle` | 2 — Emerald Nights, Jungle Run |
| `myth` | 2 — Royal Fortune, Storm Chaser |
| `pirate` | 2 — Ocean Drift, Vault Breaker |
| `wildwest` | 2 — Sunset Strip, Midnight Gold |
| `egypt` | 2 — Desert Mirage, Pharaoh's Vault |

The three cheapest symbols are no longer borrowed pictures at all: CHERRY, PLUM and LEMON are now drawn as the card royals A, K and Q, cut from a per-game material — ice, sandstone, neon, jade, ember, gunmetal, gold or enamel. That is what every cabinet worth copying does, and it is why the number below is four rather than nine.

SEVEN and BAR are drawn too and take the game's accent colour, so they differ between games without being commissioned. Replacing them with painted versions is an upgrade, not a gap.

## What a complete game needs

**Four** painted PNGs per game, named `<game-id>_<symbol>.png`:

- `DIAMOND` — the top-paying picture: the game's hero, the thing on the lobby tile
- `BELL` — second picture: the theme's other main character or object
- `WILD` — the wild — a themed object with the word WILD readable across it
- `SCATTER` — the scatter — a themed object with the word SCATTER readable across it

## Technical constraints

`scripts/check-art.mjs` rejects assets that fail these, and every one of
them is invisible until the symbol is on a moving reel on a phone:

- **Transparent background.** An opaque one shows as a grey box on a dark reel.
- **512x512, square,** subject centred and filling ~80% of the frame.
- **Consistent subject size across the set,** or symbols visibly rescale as the reel spins.
- **Distinct silhouettes.** Two symbols with the same outline and colour cannot be told apart at speed, and players dispute the result.
- **Under 200KB each.** Four per game across 23 games is still a real download.
- **Readable at 46 points.** That is the actual drawn size on a phone.
